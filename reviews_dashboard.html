איך הדשבורד הזה בנוי ומתעדכן

הנתונים מגיעים משני מקורות: הדף שגוגל עצמה מארחת לביקורות המלון (google.com/travel/hotels/entity/CgoIytfkyoX724ETEAE/reviews) ודף הביקורות של Booking.com (booking.com/hotel/il/eilat-queen-of-sheba.html) — לא Tripadvisor, זה רק לצורך השוואת דירוג.

  1. גוגל (scripts/scrape-reviews.js, Playwright): פותח את הדף, ממיין לפי "העדכניות ביותר", לוחץ על כל "להמשך קריאה" כדי לחשוף טקסט מלא, וגולל. מגבלה ידועה: גוגל טוענת אוטומטית רק כ-30 ביקורות אחרונות (בערך 9 הימים האחרונים) בכל ריצה ואז נעצרת — לא הצלחנו לעקוף את זה, וזו כנראה הגבלה מכוונת שלהם. הפתרון: הסקריפט רץ כל יום, וכל ביקורת חדשה (שזוהתה לפי hash) מתווספת למאגר הקיים — כך ההיסטוריה מצד גוגל נבנית לאט, יום אחרי יום.
  2. Booking.com (scripts/scrape-booking-reviews.js): כאן אין את המגבלה של גוגל — לדף ביקורות אמיתי עם דפדוף (220+ עמודים, כ-2,200 ביקורות סה"כ), תאריך מדויק לכל ביקורת (לא הערכה!), ופירוק ל"מה אהבו"/"מה לא אהבו" בנפרד. לכן ברגע הראשון שהרצנו את זה (04/09/2026) כבר קיבלנו כ-150 ביקורות אמיתיות מ-3.5 החודשים האחרונים — לא צריך לחכות שזה ייבנה עם הזמן כמו בגוגל. הריצה היומית ממשיכה לאסוף רק את החדש. ציון בוקינג (מתוך 10) מומר לסולם 1–5★ כדי להשתלב באותם גרפים; אין לביקורות בוקינג פירוט תת-דירוגים (חדרים/שירות/מיקום) כי הדף לא חושף את זה ברמת ביקורת בודדת.
  3. scripts/merge-and-build.js ו-scripts/merge-booking.js מפרסרים, מתייגים נושאים לפי מילות מפתח (אותה לוגיקה לשני המקורות), ומעדכנים גם snapshot יומי (data/snapshots.json) עם הדירוג הכללי בכל פלטפורמה.
  4. משימה מתוזמנת ב-Windows Task Scheduler מריצה את שני הסקריפטים פעם ביום, מוודאת עם claude -p שהתוצאה הגיונית, ודוחפת ל-GitHub. הדשבורד עצמו (reviews_dashboard.html) קורא את קבצי ה-JSON ב-fetch() בזמן טעינה — אין build step.
⚠️ לביקורות גוגל אין תאריך פרסום מדויק — רק תיאור יחסי ("לפני 3 ימים"), שהדשבורד מעריך ממנו תאריך; מדויק מאוד לביקורות טריות, פחות מדויק לביקורות שכבר היו "לפני שבוע"+ בריצה הראשונה שאספה אותן. לביקורות Booking.com יש תאריך מדויק ישירות מהמקור.

כדי לרענן ידנית: npm run update (גוגל) ו/או node scripts/scrape-booking-reviews.js && node scripts/merge-booking.js, ואז commit+push.
